# Local dashboard fonts

The dashboard uses the user-provided IRANYekanX font family locally:

- `IRANYekanX` for Persian and mixed-script UI text.
- `IRANYekanXFaNum` for numeric and data-heavy UI roles.
- Regular through Black weights are included so the existing hierarchy can keep its intended weight range.

The WOFF2 files were downloaded from URLs supplied by the repository owner on 2026-09-02. They are served by the loopback dashboard server; the browser does not fetch fonts from a CDN at runtime. Font licensing and provenance have not been independently verified in this repository.
