# چک‌لیست QA دمو صباحی

تاریخ: ۱۴۰۵/۰۶/۱۱ · ۲۰۲۶-۰۹-۰۲

## آزمون‌های انجام‌شده

- [x] اجرای محلی با Python static server روی `127.0.0.1:4178`
- [x] اجرای Chromium با wrapper نصب‌شده Playwright در حالت headless و profile ایزوله
- [x] بررسی RTL و خوانایی فارسی در viewport دسکتاپ ۱۴۴۰×۱۰۰۰
- [x] بررسی responsive در viewport موبایل ۳۹۰×۸۴۴؛ `scrollWidth` با عرض viewport برابر بود
- [x] RFQ A: یک قلم، تطبیق قوی با Pexide MV 35kV Alpha، قیمت در انتظار ورود
- [x] RFQ B: دو ابهام روشن برای گرید و استاندارد؛ بدون انتخاب حدسی
- [x] RFQ C: سه قلم مستقل با خروجی جداگانه و ابهام مشخص برای اقلام MPC
- [x] حرکت عادی بین هر شش مرحله با «بعدی» و «قبلی»
- [x] حالت ارائه از مرحله ۱ تا مرحله ۶ با «بعدی»
- [x] بستن حالت ارائه؛ لایه ارائه واقعاً hidden می‌شود و DOM آن پاک می‌شود
- [x] «شروع دوباره» از مرحله تأیید به صفحه ورودی برمی‌گردد
- [x] دکمه‌های مرجع محصول و شاخص‌های دمو و بازگشت به میزکار
- [x] تأیید انسانی فقط state نمایشی را تغییر می‌دهد؛ هیچ ارسال یا فرم فعالی وجود ندارد
- [x] کنسول Playwright پس از تست‌ها: ۰ خطا و ۰ هشدار
- [x] خروجی‌های تصویری ۰۱ تا ۰۶ با screenshot headless ذخیره شدند
- [x] مسیر پایه فقط assetهای محلی را درخواست می‌کند؛ بدون API یا font CDN
- [x] هیچ قیمت واقعی، اطلاعات خصوصی یا ادعای فرایند داخلی صباحی در داده دمو وجود ندارد
- [x] preflight شبکه پیش از کار: VPN متصل، proxy مستقیم operational، بدون تغییر پایدار سیستم

این QA نشان می‌دهد prototype محلی و مسیر ارائه قابل اجراست؛ نشان نمی‌دهد که فرایند واقعی، حجم درخواست، منبع قیمت یا معیارهای عملیاتی صباحی شناخته شده است. این موارد باید در جلسه کشف اعتبارسنجی شوند.
